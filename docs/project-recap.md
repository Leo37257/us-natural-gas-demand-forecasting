# 项目 recap — U.S. Natural Gas Demand Forecasting

> 面试前翻这一份，比重读 80 页报告快。
> 原项目：UChicago ADSP 31006 期末项目，2026-03。

---

## 一、解决什么问题

**预测美国每月天然气总消费量**，服务于能源规划、管网与储气调度、供应决策和政策分析。

问题定得很具体：**经典时间序列方法能不能对月度天然气消费给出可靠的中短期预测？**
不是"用最新的模型"，而是"够不够用、哪个够用"。

## 二、数据

| | |
|---|---|
| 来源 | 美国能源信息署（EIA）月度序列 |
| 区间 | 2006-01 – 2025-12，**240 个观测** |
| 单位 | 百万立方英尺（MMcf） |
| 训练集 | 2006-01 – 2023-12（216 个） |
| 测试集 | 2024-01 – 2025-12（**24 个 = 两个完整季节周期**） |
| 预测步长 | **h = 24，24 步提前预测** |

原始 CSV 有 4 行元数据表头、倒序存储，需跳过、重命名、解析日期、重排。

## 三、建模前做了什么，为什么

**① 可视化三件套**
时序图 → 长期上升趋势 + 强年度季节性。
季节子序列图 → **几乎每个月都在逐年上升**，不只是冬季。
季节箱线图 → **消费高的月份箱体更宽** ⇒ 方差随水平增长。

**② STL 分解**
趋势：2006 年约 1.9 → 2025 年约 2.8（百万 MMcf）。
中间有 2008–2012 平台期（金融危机）、2020 下陷（新冠）、2024–25 加速。
季节振幅约 ±50–60 万 MMcf。
残差三个尖峰：**2014 极地涡旋、2020 疫情、2025 年 1 月破纪录**。

**③ Box-Cox 变换**
Guerrero 方法估 λ，落在 0 与 1 之间（既非"不变换"也非"取对数"）⇒ 应该做变换。
**做了验证**：对比变换前后的年度标准差 — 变换前趋势线明显上扬，变换后几乎水平。

> 这是全项目方法论最扎实的一步：**变换是诊断出来的，不是流程化套上去的**。

**④ ACF / PACF + 平稳性检验**
ACF 缓慢衰减且有季节峰；PACF 在滞后 1 和滞后 12 有显著尖峰
⇒ 短期依赖与季节依赖并存，为 SARIMA 定阶提供依据。

## 四、四个模型各自在回答什么

| 模型 | 是什么 | 为什么要它 |
|---|---|---|
| **Seasonal Naïve** | 用去年同月值作预测 | **基准线**。强年周期下这个朴素方法已不差，任何模型必须超过它才算有价值 |
| **Regression (trend + season)** | `tslm(y ~ trend + season)`，线性趋势 + 12 个月度哑变量 | 把趋势和季节当**确定性成分**直接估计。报告论证了为何不差分：趋势有经济解释（煤改气、LNG 出口），差分会删掉回归能利用的信息 |
| **SARIMA(0,0,1)(0,1,1)[12]** | 季节 MA + 一阶季节差分 + Box-Cox | 显式建模**误差的序列相关**。定阶用了**族内 `tsCV`**：AICc 最低的是 (1,1,1)(0,1,1)，但 CV RMSE 最低的是更简单的 (0,0,1)(0,1,1)，选了后者，`auto.arima` 也同意 |
| **Holt-Winters（乘法）** | 指数平滑，分解为水平 / 趋势 / 季节 | 比较了加法 vs 乘法、阻尼 vs 不阻尼。选乘法是因为**季节波动随水平放大** |

## 五、怎么评估

测试集上的 **RMSE、MAE、MAPE、MASE**，外加残差诊断（Ljung-Box、Q-Q）。

**MASE 是关键**：以样本内季节朴素误差为尺度，**MASE < 1 才算赢过朴素预测**。

## 六、两个结论

### 原始结论（单次 24 个月留出）

| | RMSE | MAE | MAPE | MASE |
|---|---:|---:|---:|---:|
| Seasonal Naïve | 194,709 | 123,366 | 3.90% | 1.051 |
| Regression | 140,263 | 109,257 | 3.85% | 0.931 |
| SARIMA | 182,735 | 121,987 | 3.92% | 1.039 |
| **Holt-Winters** | **138,223** | **102,545** | **3.68%** | **0.874** |

→ 推荐乘法 Holt-Winters。结论是"抓住趋势和季节结构，比增加随机复杂度更重要"。

### 验证后结论（滚动 origin，约 100 个窗口）

| | 滚动 MASE | 留出 MASE |
|---|---:|---:|
| **Regression** | **0.93** | 0.93 |
| Holt-Winters | 1.09 | **0.87** |
| Seasonal Naive | 1.25 | 1.05 |
| SARIMA（阶数冻结） | 1.30 | 1.04 |

→ **排名反转，Regression 才是稳健赢家。** 原结论成立是因为那个测试窗口恰好
包含 2025 年 1 月的破纪录冬季，而乘法季节性天生擅长处理这种峰值。

详细论证见仓库根目录 [README](../README.md)。

## 七、面试会被问什么

| 问题 | 怎么答 |
|---|---|
| 为什么做 Box-Cox？ | 季节箱线图显示方差随水平增长；变换后年度标准差趋势线由上扬变水平 |
| 为什么回归不做差分？ | 趋势有经济解释（煤改气、LNG 出口），差分会删掉回归能用的信息 |
| MASE 比 MAPE 好在哪？ | 尺度无关，且直接对标朴素预测；MASE < 1 才算有价值 |
| 为什么 ARIMA 输了？ | 原结论认为是复杂度没带来收益；**滚动验证后发现是阶数不稳定** — 冻结阶数 MASE 1.30，让 `auto.arima` 每次重选则是 0.87。差距就是模型选择过拟合的大小 |
| h=12 为什么有断崖？ | 超过一年，依赖"最近完整季节周期"的模型（seasonal naive、SARIMA 的季节差分）只能重复两个周期前的模式；回归是确定性外推，所以没有断崖 |
| 你怎么知道结论可靠？ | **最该准备的一问**。如实答：单窗口不够，补了跨族滚动验证，结论被推翻了 |
| 下一步会做什么？ | 加天气外生变量（采暖度日 HDD）做 ARIMAX —— 所有模型的残差都在 2014 极地涡旋和 2025 年 1 月爆尖，说明缺的就是天气信息 |

## 八、一句话版本

> 我们用四族经典方法预测美国天然气月度消费，单窗口测试显示 Holt-Winters 最好；
> 我后来用约 100 个滚动 origin 重做了对比，发现排名反转 —— 真正稳健的是带趋势和
> 季节哑变量的回归，而原来的赢家只是恰好擅长那个窗口里的极端冬季。
